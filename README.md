# sentiment-analysis-nlp
A beginner-friendly NLP project for movie review sentiment classification using TF-IDF and Logistic Regression.
# Sentiment Analysis Using Python and NLP

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify movie reviews as positive or negative.

## Objective
To build a sentiment classification model using TF-IDF vectorization and Logistic Regression.

## Technologies Used
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- Matplotlib and Seaborn
- Joblib

## Dataset
NLTK Movie Reviews dataset containing 2,000 movie reviews:
- 1,000 positive reviews
- 1,000 negative reviews

## Project Workflow
1. Dataset collection
2. Data exploration
3. Text preprocessing and cleaning
4. Training and testing data split
5. TF-IDF feature extraction
6. Logistic Regression model training
7. Model evaluation
8. Custom review predictions
9. Model interpretation and saving

## Model Performance

Test accuracy: **83.25%**

Evaluation metrics:
- Negative F1-score: 0.83
- Positive F1-score: 0.84

## Project Files
- `Sentiment_Analysis_NLP.ipynb` – Complete project notebook
- `sentiment_model.pkl` – Trained Logistic Regression model
- `tfidf_vectorizer.pkl` – Fitted TF-IDF vectorizer
- `requirements.txt` – Required Python libraries

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open the notebook in Google Colab or Jupyter Notebook.
